# TUI·다국어 수정 및 재검증

2026-09-10 로컬 소스 기준. 이전 두 감사 문서는 수정 전 발견 기록이며, 현재 상태는 이 문서를 기준으로 한다.

## 수정 내용

- View 단독 모드의 미리보기 폭 0 문제: 모드별 패널 폭 계산 분리.
- View에서 Tab으로 숨은 편집기에 입력되는 문제: 보이는 패널만 포커스 순환, View 입력 보호.
- 이모지·결합문자·분해형 한글: 이동/삭제를 UTF-16 코드 단위 대신 grapheme 단위로 처리. 검색·설정·명령 입력창과 Vim 가로 이동/삭제에도 적용.
- 분해형 한글의 표시 폭을 NFC와 일치시킴. 파일명·탭·한글 버튼 클릭 좌표도 표시 폭으로 계산.
- 탭 간 빠른 입력의 Undo 병합 분리. Markdown·표 포맷에도 Undo 기록 추가.
- 수정한 탭 닫기 확인을 종료 확인과 분리하고 파일·내용에 연결.
- 저장 완료 후 다른 탭의 baseline이 바뀌는 문제 수정. 같은 파일의 저장 요청 직렬화.
- 탭 전환 후 완료된 이전 파일 watcher 읽기 결과 무시.
- Shell 결과 패널의 누락된 렌더링 복구 및 Escape 닫기 처리.
- TUI에서도 MDOK_LANG 우선 적용. ko-KR, ko_KR.UTF-8, KO 인식.
- CLI 도움말·lint·파일 메뉴·활성 검색 상태 번역 적용.
- 일본어·중국어 README가 약속하던 미구현 UI 지원을 실제 범위(한국어/영어)로 정정. 일본어·중국어 UI를 새로 구현한 것은 아님.

## 실행 결과

| 검증 | 결과 |
| --- | --- |
| TypeScript 빌드 | 통과 |
| src 단위 테스트 | 48/48 |
| 대량·다국어·Unicode 회귀 테스트 | 5,748/5,748 |
| 실제 PTY 전체 흐름 | 39/39 |
| 추가 PTY: 한국어 파일 버튼 클릭, 한국어 검색 상태, 명령 입력창 복합 이모지 삭제 | 3/3 |
| git diff --check | 통과 |

자동 테스트 합계 5,796개, 실제 PTY 시나리오 합계 42개. 마지막 검색 상태 번역 변경은 추가 PTY 실행에서 검증했다.

PTY는 실제 빌드된 Ink TUI 프로세스에 키보드·마우스 입력과 터미널 리사이즈를 전달하고 출력 및 저장 파일/세션을 검사한다. 임시 홈과 임시 문서를 사용하며 사용자 설정/문서를 변경하지 않는다. 초기 감사에서 실패했던 시나리오를 제거하지 않고 그대로 재검증했다.

```sh
npm run build
npm run test:all
npm run test:tui
```

`test:tui`는 Python 3와 POSIX PTY 환경이 필요하다. 현재 스크립트는 추가 검증을 포함한 42개 시나리오를 실행한다. 실패 시 화면 출력을 함께 기록한다.

## 한계 및 배포 상태

이는 등록된 검사 범위의 통과이며 모든 가능한 결함이 없다는 보장은 아니다. 실제 OS IME 조합 중 입력, 터미널별 폰트/RTL 표시, 물리 카메라 QR 인식, 모든 OS 조합은 이번 자동 검증 범위 밖이다. 일본어·중국어 등 문서 내용의 보존과 UI 언어 지원은 별개다.

소스와 dist 빌드를 갱신했다. 커밋·푸시·npm 게시 및 전역 설치 바이너리 갱신은 하지 않았다.
