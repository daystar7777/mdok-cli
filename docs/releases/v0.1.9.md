# mdok v0.1.9 — Explore and focused document viewing

- Full-screen **Explore** browser via the top button or `Ctrl+O`, `E`: mouse/keyboard folder browsing, filename search, hidden-file/Markdown filters, and safe Markdown creation.
- Explore replaces the current document with Save / Discard / Cancel protection for unsaved edits.
- Only the selected document is displayed. Split shows its source and preview; existing buffers are selected by name without shrinking the document area.
- Overflow names remain accessible on narrow terminals. Switching preserves unsaved buffers.
- Fix stale previews on document switches and status-bar wrapping on narrow terminals.
- Correct CLI version reporting and add a package/lockfile/built-CLI version consistency regression test. This supersedes npm v0.1.8, whose CLI incorrectly reported v0.1.7.

## Verification

- 89 real-terminal scenarios passed for this feature set, including Explore, narrow layouts, multilingual names, unsaved buffers, QR, math, and comparison.
- Package prepack runs the source and mass regression suites.
- Release CI builds macOS ARM64/x64, Linux x64, and Windows x64 executables, with native smoke checks and SHA256 checksums.

## Install or update

```sh
npm install -g @daystar7777/mdok@0.1.9
```

Node.js 22+ is required for npm installation. Standalone downloads do not require Node.
