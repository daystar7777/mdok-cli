# 검증 결함 수정 결과

앞선 `muse-mass-verification-2026-09-10.md` 및
`expanded-scenarios-2026-09-10.md`는 수정 전 실패 기록이다.
이번 수정 후 기존 실패 10개 테스트는 모두 통과한다.

## 수정 내용

- 표 셀을 이스케이프된 파이프와 실제 구분자를 구별하여 파싱한다.
  명시하지 않은 정렬을 새로 부여하지 않으며 CJK 표시 폭으로 정렬한다.
  셀 개수가 불균일한 표는 의미 변화/내용 유실을 피하기 위해 원문을 유지한다.
- 심볼릭 링크(끊어진 링크 포함)에 대한 동기/비동기 저장은 명시적으로
  거부한다. 링크와 원본을 보존하며 오류는 실제 대상 파일을 열도록 안내한다.
  링크를 자동으로 따라가 저장하지 않는다.
- SSE DONE에서 즉시 읽기를 끝내고 reader를 취소/해제한다. 토큰 콜백
  예외를 JSON 오류처럼 삼키지 않으며 잘못된 완결 JSON행은 오류 처리한다.
- Git status는 NUL 구분자를 사용한다. 한글/공백/줄바꿈 파일명과 rename의
  목적지·원본 레코드를 구분하여 실제 파일명으로 상태를 조회한다.
- 세션에서 손상 항목을 제거해도 유효한 활성 탭의 원래 정체성을 보존한다.
- 코드펜스는 같은 문자 종류, 충분한 길이, 빈 닫기 접미사를 요구한다.
- Intl.Segmenter 기반 grapheme 단위로 표시 폭·슬라이스·열 변환을 계산한다.
  🚀, 👩‍💻, 국기, 피부색 수정 이모지, 키캡의 일반적인 2칸 표시를 지원한다.
  TUI의 문자열 축약과 편집기 행 렌더링도 같은 분할 단위를 사용한다.

## 검증

- TypeScript 빌드 통과.
- `npm test`: 45 / 45 통과 (새로운 고정 회귀 사례 7개 포함).
- `npm run test:mass`: 5,130 / 5,130 통과.
- 합계 5,175 실행 건수, 실패·skip 없음.
- `git diff --check` 통과.
- `test:all`과 prepack에 두 테스트 묶음을 연결하여 배포 전 모두 검증한다.

추가 회귀 테스트는 `src/resolution.test.ts`에 있다. 파이프/정렬 조합의
HTML 동일성, 복합 이모지의 모든 내부 UTF-16 위치, NUL 파일명, dangling
symlink, 펜스 길이/종류, 닫히지 않은 전송의 DONE 취소, 잘못된 JSON을 검증한다.

## 제한

심볼릭 링크가 검사 직후 경쟁적으로 교체되는 공격까지 방어한다고 보장하지
않는다. 실제 터미널/폰트별 grapheme 폭과 카메라 스캔은 별도 검증 대상이다.
입력/삭제/커서 이동 전체의 grapheme 단위 편집을 완성했다는 의미는 아니다.
테스트의 네트워크 응답은 모의이며 실제 외부 API나 원격 Git에 쓰지 않았다.
이번 작업에서 커밋·푸시·npm 배포는 하지 않았다.
