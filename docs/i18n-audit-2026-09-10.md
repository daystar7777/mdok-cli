# 다국어 지원 검증

> 수정 전 감사 기록. 수정 후 결과는 [수정 및 재검증](fix-verification-2026-09-10.md) 참조.

## 지원 범위와 결과

현재 제품의 실제 UI 언어는 `ko`와 `en` 두 개다. 각 사전은 164개 메시지
키를 갖는다. 일본어·중국어 문서를 열 수 있는 것과 일본어·중국어 UI를
제공하는 것은 다르다.

- 새 자동 검증: **534건 / 531 통과 / 3 실패**.
- 실제 PTY 언어 흐름: **7건 / 4 통과 / 3 실패**.
- 전체 기존+확장 자동 테스트 재실행: 48/48 통과, 대량 5661/5664 통과.
- 빌드와 diff 검사는 통과. 제품 코드는 이번 요청에서 수정하지 않았다.

## 번역 사전 전수 검사

한국어/영어의 모든 키에 대해 비어 있는 값, 필수 치환 변수 차이, 실제 치환,
UTF-16 유효성을 검사했다. TUI/CLI의 리터럴 t()/ct() 호출도 AST로 탐색해
없는 키를 참조하지 않는지 검사했다. 모두 통과했다.

영어 `msg.formatted`의 `{es}`는 복수형 접미사이며 한국어에는 불필요하다.
이를 의도적인 문법 차이로 명시하고 누락 결함에서 제외했다.
문자열의 전문적인 언어학적 감수/용어 일관성까지 자동 검사한 것은 아니다.

## 확인한 문제

| 항목 | 증거/영향 |
| --- | --- |
| 일본어 UI 지원 표기 불일치 | README.ja.md는 일본어 UI를 지원한다고 하지만 `normalizeLang('ja')`는 en |
| 중국어 UI 지원 표기 불일치 | README.zh-CN.md는 중국어 UI를 지원한다고 하지만 `normalizeLang('zh-CN')`는 en |
| TUI가 언어 환경변수 무시 | en 설정+MDOK_LANG=ko, ko 설정+MDOK_LANG=en 모두 설정 언어로 표시 |
| 한국어 UI에 영어 제목 | 실제 파일 메뉴 제목이 `File`로 남음 |
| 분해형 한글 표시 폭 오류 | 완성형 `한`은 2칸, NFD `한`은 4칸으로 계산 |

추가 CLI 실행 확인: `MDOK_LANG=ko node dist/index.js --help`의 도움말은
영어로 표시된다. 옵션/설명과 lint의 진단 본문 등도 하드코딩 영어가 남아 있다.
이 수동/코드 검사 결과는 위 534개 테스트 실패 수에 합산하지 않았다.

언어 환경변수의 우선순위는 모든 README가 TUI/CLI 공통으로 약속하지만,
CLI는 환경변수를 확인하고 TUI는 `cfg.lang`만 읽기 때문에 동작이 다르다.

| 한국어 사이드바 제목 | 통과 |

사이드바 데이터에 `Files`라는 리터럴은 있지만 렌더링은 번역 키를 사용하므로
실패로 분류하지 않았다. 정적 문자열 검색만으로 판정하지 않은 사례다.

## 문서 데이터와 locale 검증

한글, 일본어, 간체/번체 중국어, 아랍어, 히브리어, 힌디어, 결합 악센트,
복합 이모지, NFD 한글 10개 샘플을 3개 QR 화면 크기로 테스트했다.
파일명과 본문이 gzip/Base64에서 바이트 손실 없이 복원되는 30건 모두 통과했다.

`ko-KR`, `ko_KR.UTF-8`, `KO`는 현재 en으로 fallback한다. 이는 지역 locale
정규화 미지원으로 별도 기록했으며 정확히 ko/en만 받는 현재 API의 실패로
중복 집계하지 않았다. 일본어/중국어는 README 지원 약속과의 불일치로 검사했다.

## 재실행

```sh
npm run build
node --import tsx --test tests/i18n-audit.test.ts
python3 scripts/audit-tui.py i18n
```

테스트 파일: `tests/i18n-audit.test.ts`.
PTY fixture는 매번 독립된 임시 설정/문서로 실행하고 사용자 설정을 읽거나
바꾸지 않는다. 네트워크 LLM/원격 서비스는 사용하지 않았다.

## 미검증 및 후속 범위

- OS의 실제 한국어/일본어/중국어 IME 조합 이벤트
- RTL의 방향·shaping·커서·선택 시각적 정확성 (문자 보존과 다름)
- 터미널/폰트별 표시 폭, 마우스 드래그 및 CJK 파일명 클릭 좌표
- 장문 번역의 모든 화면 크기 레이아웃과 접근성
- 전문 번역 품질 검수

헤더/탭 클릭 좌표 일부가 표시 폭 대신 `.length`를 사용하는 코드 위험은
계속 남아 있다. 실제 좌표 오류를 재현한 검증 건수에는 포함하지 않았다.
커밋·푸시·배포는 수행하지 않았다.
