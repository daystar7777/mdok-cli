# mdok CLI 0.1.11 — safe saves and visible preview loading

## 변경 사항

- 일반 저장·탐색기의 저장 후 열기·원본 자동 저장·수식 변환 저장 전 디스크 변경 검사.
- 약 1초 간격의 외부 변경 확인. 기본 확인 요청, 깨끗한 버퍼만 자동 반영, 현재 내용 유지.
- Ctrl+O u: 다시 읽기, 명시적 미저장 편집 버리기 확인, 비교, 별도 사본 저장.
- 기본 OFF인 원본 자동 저장. 충돌·삭제·읽기/쓰기 실패 시 멈추며 새 입력은 늦은
  저장 완료 응답으로 덮어쓰지 않습니다.
- 정규 경로/파일 ID를 이용한 중복 열기 처리와 mdok 동시 저장 잠금.
- 실행별 미저장 복구 사본과 `mdok recover [id]`. 오래된 복구 기록은 원본을 자동 덮어쓰지 않습니다.
- 별도 작업 스레드의 미리보기와 읽기/갱신 중 표시. 한국어·영어 UI.

## 업데이트

```sh
npm install -g @daystar7777/mdok@0.1.11
mdok --version
```

Node.js 22 이상이 필요합니다. 아래 독립 실행 파일은 Node 없이 사용할 수 있으며,
해당 플랫폼/아키텍처를 선택하세요. 이 릴리스는 데스크톱 DMG 업데이트가 아닙니다.

외부 앱의 미저장 내용은 감지할 수 없고 자동 병합/강제 덮어쓰기는 없습니다.
복구 데이터는 로컬 평문이며 백업이 아닙니다. 다른 앱까지 포함한 OS 공통 저장
트랜잭션이나 모든 파일 시스템에서의 원자성을 보장하지 않습니다.
하드 링크 파일의 원본 교체는 차단되며 사본 저장이 필요합니다. 강제 종료 뒤 남은
저장 잠금은 편집기들이 종료됐음을 확인하기 전 삭제하지 마세요.

See [file safety and recovery](https://github.com/daystar7777/mdok-cli/blob/v0.1.11/docs/file-safety.md)
for operating instructions, recovery/privacy details and known limits.

## English

Adds guarded original-file writes, external-change policies, opt-in idle auto-save,
explicit reload confirmation and conflict copies. Duplicate aliases reuse a tab;
cooperative locks guard concurrent mdok writes. Independent plaintext recovery
snapshots are available through mdok recover. TUI preview rendering moves off the
UI thread and shows pending status. Existing CLI engines, QR and desktop bridge
remain available; no desktop installer, account/sync service or Chrome extension
is included. Keep independent backups and review the documented limitations.
