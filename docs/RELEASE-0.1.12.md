# CLI 0.1.12

Integrates the 0.1.11 external-file conflict guards, opt-in autosave and preview
loading fixes into the main development line. Adds isolated regression scenarios
for desktop app discovery, compact toolbar display and the unsaved-file guard.
No PDF editing is added to the CLI; PDF reading/annotations are desktop features.

Update: `npm install -g @daystar7777/mdok@latest` (Node.js 22+).
