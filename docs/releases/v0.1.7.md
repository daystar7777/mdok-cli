# mdok 0.1.7 — Math authoring and Markdown-aware comparison

- Math syntax highlighting and structural/engine diagnostics: basic, KaTeX 0.18.7, restricted MathJax 4.1.3.
- Ctrl+O M: math tools, diagnostic navigation, delimiter conversion with preview, explicit confirmation and single Undo.
- Ctrl+O D: Markdown block/word/table-cell/math-token comparison, raw/side-by-side views, search and scrolling.
- Read-only Git staged/unstaged/commit snapshots, including first-commit repositories.
- Worker-backed analysis with cancellation and time/resource budgets.
- Korean/English UI strings and narrow-terminal fixes. Viewer-first/Enter-to-edit behavior retained.
- Standalone builds embed both analysis workers and math engines. CI smoke-tests native binaries outside the repository directory.

## Install / upgrade

```sh
npm install -g @daystar7777/mdok@0.1.7
```

Node.js 22+ is required for npm installation. Standalone downloads do not require Node.
SHA256SUMS.txt covers the attached executables.

## Scope

This is math **authoring/validation**, not typeset math in the TUI. Markdown analysis
supports CommonMark/GFM, not all Pandoc extensions or arbitrary TeX packages.
Math settings are session-local; macros are configurable through the CLI.
Fonts are not bundled or installed. Windows font rendering still needs real-user verification.
See docs/math-tools.md for limits and docs/math-verification-2026-09-11.md for testing details.
