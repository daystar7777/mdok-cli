## 새로 재현된 결함

1. 표의 `a\|b`를 `split('|')`가 여러 셀로 나눠 렌더링 의미를 바꾼다.
   문서 의미 보존 문제이므로 우선 수정해야 한다.
2. `strWidth('🚀')`가 2 대신 1을 반환한다.
3. `strWidth('👩‍💻')`가 일반적인 결합 이모지 2칸 정책 대신 5를 반환한다.
   실제 터미널/폰트의 grapheme 지원에 따라 표시 폭은 달라질 수 있다.

Muse의 결과 재검토도 위 세 실패를 유효한 문제로 판단했고 표 의미 변경을
우선 수정하도록 권고했다. 모델은 결과 요약을 검토했으며 직접 실행하거나
전체 저장소를 감사한 것은 아니다. 이번 요청에서는 제품 코드를 수정하지 않았다.

## 재실행

```sh
npm run build
npm test
npm run test:mass
node --import tsx --test --test-name-pattern='golden escaped pipe' tests/muse-audit.test.ts
```

추가한 테스트는 `tests/mass.test.ts`, `tests/muse-audit.test.ts`에 있으며
현재 `test:mass`는 재현된 세 결함 때문에 종료 코드 1을 반환한다.

## 남은 검증 범위

- 터미널/폰트별 실제 grapheme·카메라 스캔 검증
- QR 수신기의 악성 헤더, gzip 폭탄 방어 (수신 구현 자체가 없음)
- 디스크 고갈·fsync 내구성·심볼릭 링크 정책
- 입력 escape 시퀀스의 모든 분할 경계와 bracketed paste
- 네트워크 LLM 오류/취소의 전체 상태 전이 (현재는 모의 스트림)
- 코드 커버리지 측정 및 생성 실패 케이스 자동 축소

커밋·푸시·npm 배포는 수행하지 않았다.
