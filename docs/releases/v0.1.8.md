# mdok v0.1.8

## Explore and focused document viewing

- New full-screen **Explore** file browser, opened from the top button or `Ctrl+O`, `E`.
- Browse folders with keyboard or mouse, search names, filter Markdown files, show hidden files, and create Markdown documents.
- Explore replaces the current document, with Save / Discard / Cancel protection for unsaved edits. Existing files are never overwritten when creating a document.
- Display only the selected document. Split mode shows that document's source and preview, not multiple documents side by side.
- Switch existing buffers using file-name tabs; narrow terminals provide previous/next name navigation and preserve unsaved edits.
- Fix stale previews when changing files and status-bar wrapping on narrow terminals.
- Preserve full document width regardless of the number of open buffers.

## Verification

- 300 source tests and 5,844 mass regression cases passed.
- 89 real-terminal scenarios passed, including mouse input, multilingual names, narrow layouts, unsaved buffers, Explore, QR, math tools, and Markdown comparison.
- Native macOS standalone smoke checks passed. Release CI builds macOS ARM64/x64, Linux x64, and Windows x64 binaries and checks each native platform.
